ROSELN VILLAGE (family book) + ROSELN VILLAGE MAP  -  public edition
=====================================================================

The public edition of Roseln Families. It is built from the same sources, but uses only:
  - Ortsfamilienbuch Roseln bis 1925 (Thomas Albrich), the authority for dates
  - Ortsfamilienbuch Magarei
  - Christian Weiss, Roseln mitten in Siebenbürgen (2010): notes, house lists and photographs
plus family photographs and headstone photographs from the Saxon cemetery, Roseln (Randy Harris, 2016 and 2018).
Headstone names of anyone born after 1925 are shown by surname only.

Pages: index.html (Roseln Village, English), familien.html (Roseln Dorf, German), map.html (Roseln Village Map),
karte.html (Dorfplan Roseln). Data in data/, photographs in weiss/, family/, headstones/ and photos/.

This folder IS the website; nothing needs installing. Put it online as its own Netlify site (drag the
folder onto https://app.netlify.com/drop, then rename the site, e.g. roseln-village), or publish the GitHub
repository with GitHub Pages. Opening index.html straight from the computer does not work (the browser blocks
the data files); use the web address, or run "python -m http.server" in this folder and open http://localhost:8000 .
